Quad Solution - Trivia Questions Assignment

Introduction
Welcome, and thank you for taking a look into my project.
Over the past 2 weeks, I have been working on an assignment provided by Quad Solutions. The objective of this assignment
was to develop an simple to use app that retrieves questions and checks the user's answers after completing the quiz.

Important Requirement for the assignment:
- Correct answers must not be visible to users in the application (F11) tab.
The application consists of two separate components that form the QuizApp: a Frontend and a Backend.

Technologies Used

Development tools:
- Visual Studio 2026 
- Visual Studio Code
- Postman

Programming languages and frameworks:
- Java
- Spring Boot
- Vue.js
- Javascript
- HTML
- CSS

Requirements
To run the application locally on your own PC, make sure you have the following installed:
- Java JDK
- Node.js and npm
- An code editor (Visual Studio 2026 and Visual Studio Code is recommended)

Installation and Setup
First to start off with is to download or clone the repository to your local computer.

1. Starting the Backend
- Open Visual Studio Code
- Select File --> Open Folder
- Navigate to the AppQuad folder
- Open the Backend folder.
- Select the demo folder.
- Start the Spring Boot application

2. Starting the Frontend
- Open your preferred code editor (Visual Studio 2026 is what I used and is recommended)
- Select Open Folder
- Navigate to AppQuad folder
- Open Frontend folder.
- Select the QS_Frontend project.
- Run the frontend application.

Important Sidenote:
note that you have to have NPM or Node.js installed for the frontend to work, as well as the other required technologies used mentioned earlier in the README.file

Using the Application
To test the application you will need to start the backend first, followed by the frontend.

Once both components are running:
- Open the frontend application in your browser. (if done correctly the questions should appear in the window)
- Complete the quiz by answering the available questions.
- After submitting your answers, the application showcases your results.
- The results include the number of correct and incorrect answers of the questions and your final score.

Enjoy testing AppQuad!
